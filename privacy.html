Политика конфиденциальности

Эта политика описывает использование данных Google в интеграции GSF Calendar с личным органайзером GSF.

Какие данные доступны приложению

После согласия пользователя Google предоставляет адрес электронной почты и идентификатор аккаунта для сопоставления подключения; список доступных календарей; сведения о событиях, включая название, описание, место, начало и окончание, часовой пояс, статус и доступные сведения об участниках. Конкретный состав зависит от события и прав пользователя.

Интеграция запрашивает openid, userinfo.email, calendar.readonly и calendar.events. Последнее разрешение допускает создание, изменение и удаление событий. Доступ к Gmail, Google Drive и Google Tasks для этой интеграции не запрашивается.

Зачем используются данные

Данные нужны для отображения расписания, проверки занятости, планирования и выполнения поручений пользователя о встречах. Фоновая служба периодически сохраняет снимок ближайших событий. Изменения событий и приглашения выполняются в рамках поручений пользователя.

Хранение и обработчики

OAuth-токены хранятся в защищённых серверных файлах постоянного хранилища OpenClaw на Amvera. Сервер обновляет доступ через Google OAuth без хранения пароля Google. GSF хранит данные синхронизации в своей базе данных; настройки не зависят от открытой вкладки или работающего компьютера пользователя.

Данные обрабатываются Google, серверными компонентами GSF и OpenClaw и поставщиком хостинга Amvera в объёме, необходимом для работы интеграции. При обращении к подключённому AI-помощнику необходимые для поручения сведения могут обрабатываться настроенными поставщиками AI. OAuth-токены не предназначены для передачи AI-моделям.

Доступ к серверной информации предназначен для авторизованного пользователя и технического сопровождения в объёме, необходимом для эксплуатации, устранения ошибок и выполнения его поручений. Данные календаря не публикуются на этом сайте.

Ограниченное использование данных Google

Использование и передача данных, полученных через Google API, осуществляются в соответствии с Google API Services User Data Policy, включая требования Limited Use. Эти данные используются для заявленных пользовательских функций. Они не продаются, не используются для персонализированной рекламы и не предназначены для обучения универсальных AI-моделей.

Срок хранения и удаление

Токены сохраняются, пока подключение используется, до отзыва, истечения действия или удаления. Для отображения расписания GSF хранит актуальный снимок; успешно полученный новый снимок заменяет предыдущие события. При ошибке синхронизации предыдущий снимок может оставаться доступным с признаком устаревания.

Отозвать доступ можно в настройках подключений Google Аккаунта. Это прекращает доступ к Google, но само по себе не удаляет уже сохранённые в GSF сведения. Для удаления сохранённого подключения, снимков и связанных данных пользователь должен направить сопровождающему явное поручение через свой авторизованный канал GSF. Записи, которые пользователь отдельно сохранил как встречи или задачи, могут потребовать отдельного удаления.

Этот информационный сайт

Страницы размещены на GitHub Pages. Они не содержат аналитических скриптов, форм входа или обработки календаря. GitHub может вести технические журналы посещений, включая IP-адрес, согласно политике конфиденциальности GitHub.

Связь и изменения

Общие вопросы можно направить через репозиторий страниц GSF Calendar. Публичные обращения не должны содержать личные данные, содержимое календаря, пароли или токены. Чувствительные запросы обрабатываются через авторизованный канал GSF. При изменении практики обработки эта страница обновляется с указанием даты.
